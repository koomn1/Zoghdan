# زغدان | Zoghdan

متجر عربي للعطور والبخور والعود والزجاجيات، مبني بـ PHP وMySQL.

## تشغيل المتجر

1. ارفع ملفات المشروع إلى استضافة تدعم **PHP 8.1+** و**MySQL**، مثل cPanel.
2. أنشئ قاعدة بيانات ومستخدم MySQL، ثم امنحهما الصلاحيات اللازمة.
3. افتح `install.php` من نطاقك وأدخل إعدادات قاعدة البيانات وبيانات المدير.
4. سجّل الدخول إلى `/admin`، ثم حدّث بيانات المنتجات والأسعار والمخزون وبيانات التوصيل.
5. راجع دليل [التثبيت الكامل](INSTALL_ZOGHDAN_AR.md) قبل الإطلاق.

> المنتجات والأسعار التي ينشئها المثبّت أمثلة فقط؛ استبدلها ببياناتك الفعلية قبل استقبال الطلبات.

## استضافة GitHub Pages

**هذا المشروع لا يعمل مباشرةً على GitHub Pages**؛ فالمنصة تستضيف الملفات الثابتة ولا تنفّذ PHP أو تتصل بقاعدة MySQL. المستودع يحتوي مصدر المتجر كاملاً، لكن تشغيل السلة والطلبات ولوحة الإدارة يتطلب استضافة PHP/MySQL. إذا أردت نسخة تعمل على GitHub Pages، فستحتاج إلى تحويل مستقل إلى واجهة ثابتة، مع توضيح أن وظائف الطلبات والإدارة لن تعمل دون خدمة خلفية.
